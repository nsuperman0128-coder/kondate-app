# Kondate Phase2 300品版

元ファイル：Downloads/Kondate_PWA_Phase2_LocalDB.zip
作成日：2026年10月20日

## 収録内容

既存48品をそのまま残し、家庭向けアレンジ252品を追加した合計300品です。和食・洋食・中華・インドネシアを各75品収録しています。追加分には食材や味付けを変えたバリエーションを含みます。300種類の伝統料理を再現したものではありません。

## 追加した機能

- 今日の献立の料理名、週間献立の各料理、レシピ一覧のカードを押すと詳細が開きます。
- 全300品に材料・分量・調理時間・基準人数・作り方・メモを収録しました。
- 材料データは1人分を基準にし、詳細では条件設定の人数に合わせて表示します。
- 閉じるボタンまたはEscapeキーで戻れます。お気に入り操作は料理を開く操作と分かれています。
- レシピ一覧に料理名・材料の検索とジャンル絞り込みを追加しました。空白や読点で区切ると、複数の検索語をすべて含む料理を探せます。献立作成の条件設定とは独立した表示用の絞り込みです。
- レシピはすべて同梱しています。外部API、フォント、CDNは使用しません。
- recipes.jsを初回のキャッシュ対象に追加し、キャッシュの版を更新しました。

## GitHub Pagesへの反映

1. ZIPを展開します。
2. 展開先のindex.html、app.js、recipes.js、styles.css、sw.js、manifest.webmanifest、iconsフォルダーなどを既存リポジトリのルートへ上書きアップロードします。ZIP自体をアップロードする方式ではありません。
3. GitHub Pagesの公開処理が完了したら、オンラインでアプリを開き直してください。旧版が見える場合はいったんタブとホーム画面のアプリを閉じて再度開いてください。
4. 初回のオンライン読み込みと保存が完了してから、オフライン動作を確認してください。

ビルド操作は不要です。相対パスなので /kondate-app/ のようなサブディレクトリにも配置できます。

## 保存済みデータ

kondate.settings、kondate.today、kondate.week、kondate.shopping.v2の保存キーを維持しています。同じURL・同じブラウザーで更新すれば、条件設定、既存の献立、お気に入り、購入済みチェックを引き継ぐ設計です。

保存済みの買い物リストは更新時に作り直しません。追加した調味料をリストに含めたい場合は「週間 → 再作成」を押してください。この操作は元版と同様、週間献立と買い物リスト・購入済みチェックを作り直します。「条件を保存」も元版同様に献立とリストを再作成します。

レシピ詳細は保存済み献立のIDから最新の料理データを参照します。閲覧だけで献立や買い物リストは変更しません。

## 検証結果

### 検証済み（Nodeによる自動検証、DOM・保存領域・Service Worker APIは模擬環境）

- JavaScript構文チェック：app.js、sw.js。
- 300品のIDの重複がないこと、材料・正の分量・単位・基準人数・時間・3手順以上・メモの存在。
- 全300品の詳細内容生成と閉じる操作。
- 既存48品のデータ完全一致、300品の料理名重複なし、各ジャンル75品。
- 検索の複数語一致、ジャンル変更、検索結果0件・全件への復帰、検索語のHTML非挿入。
- 今日・週間・一覧の3箇所の詳細表示用ボタンの生成。
- 設定人数1〜5人・全300品（1,500通り）の買い物量計算、および詳細の2人・4人の材料量計算。
- Phase2の保存済み献立、お気に入り、購入済みチェックの起動時維持。
- ジャンル・苦手食材の候補絞り込み、7日分の再作成。
- 買い物量の人数計算、冷蔵庫の食材の除外、追加調味料の集計。
- Service Workerのインストール対象ファイルの存在、recipes.jsの収録、旧Kondateキャッシュの削除、他アプリのキャッシュの維持。
- ZIP内のファイル構成・内容一致。

### 未検証

- 実ブラウザーでの表示・タッチ・スクロール・フォーカス・画面幅ごとのレイアウト。確認用ブラウザーからローカルサーバーへの接続がタイムアウトしたため、表示確認は完了していません。
- 実ブラウザーでの通信遮断後の起動、旧Service Workerからの切り替え。
- GitHub Pagesへの実際のアップロード・公開確認。
- iPhone Safariとホーム画面追加後のPWA実機動作。
- 実際の調理、味、分量・時間の妥当性。家庭向けに記述した簡略レシピで、調理時間は目安です。

ブラウザーのdialog要素に対応する環境が必要です。米の分量は炊く前の重量で、炊飯時間は料理の調理時間に含めていません。水分や調味料は製品表示に合わせて調整してください。
