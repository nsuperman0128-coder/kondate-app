# Kondate PWA - Phase 2 Local DB

完全無料・外部APIなしのローカル献立データ方式に更新した版です。

## 追加した内容
- 48品のローカル献立データ（和食・インドネシア・中華・洋食 各12品）
- 朝食 / 昼食 / 夕食の適性
- 簡単 / 節約 / 高タンパク / 野菜多め / 辛いものOK タグ
- 設定条件を考慮した献立抽選
- 苦手食材を含む料理の除外
- 冷蔵庫食材を使う料理の優先
- 1週間で同じ料理をできるだけ重複させない
- 人数に応じた買い物量の自動集計
- 冷蔵庫にある食材を買い物リストから除外
- 週間献立を作り直すと買い物リストも自動更新
- Service Workerで recipes.js もオフラインキャッシュ

## データについて
レシピ名・タグ・材料量はアプリ内に同梱した初期データです。外部サイトやAPIから取得していません。
材料量は買い物リスト作成用の概算値で、厳密な調理レシピではありません。
